For my presentation I chose to look at Google Collab! It is a great resource when teaching python as it allow you to share activities and code you wrote! Additionally you can run code within Google Collab and see immediate results allowing your students to experiment! I very much reccomend it!
 
 
 
 
 
Directions:
Create a google collab file.
Every google collab file already has python downloaded but if you want any additional packages run %pip install followed by the name of the package.
You can create a text or code box by hovering at the bottom or in between two already existing boxes and selecting your desired type of box.
To edit a text box double tap it. You can make the text bigger with the TT option and add italics by either selecting the italics option or surrounding your text with * *. Similarly you can type in bold with ** **. If you want to type in a different color font use
<font color="COLOR NAME HERE">TEXT HERE<font>
You can type your code in the text box and it will run like normal python. If there is an error in your code Google Collab will alert you and give you an error message.
If you wish to run all code at once you can select the "Run All" option on the top bar. In the same area there is a pull down menu if you hover over the area. If you wish to delete all of the outputs click "Clear All Outputs."
Similar to a google doc you can share a Google Collab file the same way! In the same way you can create a copy of the file for your students.
